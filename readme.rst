DHF Prone Areas WebGIS 🦟🌍

This WebGIS project visualizes Dengue Hemorrhagic Fever (DHF) prone areas using spatial analysis and geospatial data processing. The platform provides an interactive map to help identify high-risk regions based on various factors, such as population density, environmental conditions, and historical DHF cases.

Features
✅ Interactive Mapping – Displays DHF-prone zones with a user-friendly interface.
✅ Geospatial Analysis – Utilizes GIS techniques to analyze risk factors and visualize spatial patterns.
✅ Data Integration – Incorporates various spatial datasets (e.g., health records, demographic data, environmental variables).
✅ Web-based Platform – Developed using Leaflet, OpenLayers, or ArcGIS API, allowing seamless web access.

This project aims to support public health efforts, decision-makers, and researchers in mitigating DHF risks through geospatial insights.
